# Backend Engineering Lab

A Next.js e-commerce project for learning backend engineering by building a reliable order workflow. The learning plan and system design are in the [backend learning roadmap](../BACKEND-LEARNING-ROADMAP.md).

## Requirements

- Node.js 20.9 or later
- npm

## Run locally

From the workspace root in PowerShell:

```powershell
Set-Location .\storefront
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```powershell
npm run dev
npm run lint
npm run build
npm run start
```

The app is currently a starter shell. Database, queue, worker, and test commands will be added as those parts are taught and implemented.
